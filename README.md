# algopack-releases

AlgoPackは、**Competitive Debug Studio**で利用できる問題パックです。

各リリースには、1つ以上のAlgoPackが添付されています。
利用したい問題のAlgoPackをダウンロードしてご利用ください。

## ダウンロード

最新のAlgoPackは **Releases** からダウンロードできます。

https://github.com/yuki6868/algopack-releases/releases

## 使い方

1. Releasesから利用したいAlgoPackをダウンロードします。
2. Competitive Debug Studioを起動します。
3. 問題パック画面からAlgoPackをインポートします。

## 収録内容

AlgoPackには、問題ごとに以下の情報が含まれています。

* 問題情報
* 参照実装（Reference Solution）
* テストケース生成設定
* メタデータ

## ライセンス

各問題の著作権は、それぞれの問題提供元に帰属します。

AlgoPackはCompetitive Debug Studioで利用することを目的としたデータパックです。
